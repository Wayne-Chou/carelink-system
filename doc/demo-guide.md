# CareLink 展示導覽

依實際展示順序，從生活近況評估（填寫、判讀、橘燈開案、黃燈提供資源）開始，接到健康管理員的個案流程、資源端回報、待辦頁，最後是後台資源管理與民眾端查詢，全程約 25 分鐘。所有資料皆為虛構的示範資料。

## 事前準備

1. 到 `/register` 註冊一個 **Email 含 `admin`** 的帳號（例如 `admin@example.com`），首頁右上角才會出現「資源管理」。註冊後會自動登入。
2. 進入「資源管理」，按「載入示範資料」，選 **「清空後只放示範資料」**。每次排練前都可以這樣重設，但會刪除所有自建的資源、個案與評估。
3. 展示中的操作（填寫評估、判讀、回報、記錄追蹤）會改動示範資料。展示結束後，再載入一次並選「清空後只放示範資料」即可還原。

> **日期都是相對的**：示範資料的日期以「載入當天」為基準往前或往後推算，任何一天載入，逾期天數與到期狀態都和本導覽相同。下表的「前 N 天」「後 N 天」都是相對於載入當天。
>
> 資料存在瀏覽器分頁（sessionStorage），關閉分頁就會清空，需要重新登入並載入示範資料。
