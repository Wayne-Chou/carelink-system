# 待與委託方確認事項

最後更新：2026-10-28

三份規格（doc/specs/ 的資源、評估與個案、帳號）中所有待確認事項都集中在這裡，依主題分組。規劃中計畫自己的待確認事項留在計畫文件內（例：doc/plans/sites-plan.md）。

| 標示 | 意義 |
| --- | --- |
| ✅ 已確認 | 委託方已回覆，附結論；尚未實作的另外註明 |
| ⏳ 待確認 | 尚待委託方回覆，附原型目前的做法 |
| ⛔ 已過時 | 題目已不適用，附原因 |

「目前做法」中以 `設定名稱` 標示的，是寫在 src/config/ 的設定值，確認後改設定即可。出處：資源 = doc/specs/resource-schema.md、評估 = doc/specs/assessment-schema.md、帳號 = doc/specs/account-schema.md。
